# 脆奶酪小红书评价整理

本仓库是对小红书上「脆奶酪」相关公开笔记与评论的静态整理展示站点，便于检索与阅读。

## 说明

- **内容来源**：从小红书公开页面抓取的笔记标题、正文、图片与评论，仅供研究与展示。
- **非官方**：本项目**不隶属于**小红书或伊利（及其「脆奶酪」产品），亦非其合作或背书页面。
- **用途**：个人/研究用途的公开评价整理；请勿将本页内容当作官方宣传或购买依据。

## 使用方式

本站点为纯静态页面，无构建步骤，可直接用 GitHub Pages 托管：

1. 将本仓库推送到 GitHub（用户自行操作）。
2. 在仓库 Settings → Pages 中启用 GitHub Pages（Source 选分支根目录或 `/docs`，视你放置路径而定）。
3. 访问 `https://<用户名>.github.io/<仓库名>/` 即可。

本地预览：用任意静态服务器打开 `index.html`，或直接在浏览器打开（部分浏览器对本地相对路径有限制，建议用简单 HTTP 服务）。

## 目录结构

```
index.html          # 笔记列表
notes/<id>.html     # 单篇详情（含全部评论与回复）
images/<id>/        # 笔记图片
data/notes.json     # 笔记元数据（可供前端筛选）
style.css           # 样式
```
